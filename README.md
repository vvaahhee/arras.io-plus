# arras.io+

arras.io+ is an arras.io client which aims to improve user experience by providing much better optimization and many
new features.

## Install

1. Install [Tampermonkey](https://www.tampermonkey.net/) or [Violentmonkey](https://violentmonkey.github.io/).
2. Install [arras.io-plus.user.js](https://raw.githubusercontent.com/vvaahhee/arras.io-plus/main/arras.io-plus.user.js).
3. Go to [arras.io/+](https://arras.io/+).

If you have any questions join https://discord.gg/NGR7grKXXR or message me on Discord @vvaahhee.
